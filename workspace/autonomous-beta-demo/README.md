# Autonomous Beta Demo

This isolated static page is the bounded target for Supervisor v0.9 product validation. It has no build step, package manager, external assets, persistence, or network access.

Baseline behavior:

- renders a fixed release checklist;
- filters items by all, open, or complete;
- updates visible and completed counts;
- keeps all implementation inside this directory.

Open `index.html` directly in a browser to inspect the demo.
