Status: local release-candidate gates passed; public release remains blocked by repository state and operator-owned metadata decisions.

This document records the evidence used to decide whether the current checkout is ready for a public v1.0-beta release. The release-preparation work is intentionally limited to documentation, installation, release checks, Dashboard presentation, isolated acceptance fixtures, and tests. Task Runtime, Harness audit, approval, Resource Profiles, Workflow definitions, and security boundaries remain frozen.

## Conditional real-provider acceptance

The configured Claude CLI was present (`2.1.201`), but the fixed isolated Provider Preflight timed out three times: twice at the normal 60-second gate and once at a 30-second confirmation gate. All probes used an empty system temporary directory, no project content, no tools, no modifications, and no session persistence. The latest failed probe completed at `2026-07-16T13:34:03.758Z` with classification `provider_timeout`.

The second result was persisted and independently observed through both the Dashboard API and offline `doctor`; the UI showed `Provider timeout` with recovery guidance. In accordance with the safety boundary, no paid Workflow, Planner, approval, Coder, or Reviewer was created, and the Todo baseline was not modified manually to imitate successful dogfood. ## Release decision

- **Local v1.0-beta candidate:** pass. Installation, startup, Runtime, MCP, Harness, Dashboard, responsive UI, release files, and hygiene gates are green.
- **Public tag/publish:** no-go in the current checkout. The accumulated candidate changes are uncommitted, so the clean-worktree release gate correctly fails.
- **Release branch:** the current branch name still identifies the older `supervisor-v0.7-rc` line. Select an intentional v1.0-beta release branch before committing or tagging.
- **Author metadata:** reachable Git history contains a non-noreply author address. History rewriting is explicitly outside this task; the repository owner must either accept that public identity exposure or sanitize history before publication.
- **External acceptance:** conditionally skipped because Provider Preflight failed. This is recorded as an external availability risk rather than bypassed.

Before a public tag:

1. Review and commit the intended release-candidate diff on an appropriate v1.0-beta release branch.
2. Decide whether the non-noreply author metadata is acceptable for a public repository; do not rewrite history accidentally.
3. Run `scripts/check-release-baseline.ps1` without `-SkipGitClean` and require a clean pass.
4. When Provider connectivity is restored, run the isolated Todo request through the full supervised Workflow and append its IDs/result here.
