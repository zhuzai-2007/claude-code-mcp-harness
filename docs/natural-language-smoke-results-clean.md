# Natural-Language Smoke Results

This log tracks ordinary user prompts translated by Codex into bounded Claude Code worker tasks.

## Result Keys

- `raw_prompt`: the prompt as a user might ask it, summarized in ASCII when needed to avoid terminal encoding drift.
- `worker_prompt`: the bounded task generated by Codex.
- `run_id`: Claude worker run id.
- `fix_runs`: follow-up worker run ids if supervisor validation failed.
- `supervisor_checks`: checks Codex ran independently.
- `result`: pass, fixed-pass, pass-with-worker-budget-failure, blocked, or fail.
