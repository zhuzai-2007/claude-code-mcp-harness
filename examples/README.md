# Examples

These examples are preserved outputs from worker smoke tests. They are useful for inspecting artifact shape and validating supervisor review habits, but they are not part of the runtime harness.

- `cc-worker-static-habit-tracker/`: dependency-free static web app created by a Claude Code worker and repaired through a bounded fix run.
- `cc-worker-study-task-planner/`: small Python CLI example with a standard-library test script.

Runtime worker output should go under `workspace/`, which is ignored by Git.
